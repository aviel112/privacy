Aviel Shorts Uploader — Privacy Policy

Last updated: October 20, 2026

Aviel Shorts Uploader is a private tool used only by Aviel Amira to publish his own short fitness videos to his own YouTube channel. It is not offered to the public and has no other users.

What data the app accesses

With the channel owner's consent, the app uses the YouTube Data API to upload videos to the owner's channel, read basic channel information (channel name and ID), and post or manage comments on the owner's own videos.

How data is stored

The OAuth tokens are stored only on the owner's personal computer. No data is sold, shared with third parties, or sent to any server other than Google's own APIs.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
